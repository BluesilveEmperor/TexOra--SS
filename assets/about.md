# About TeXora

**Your ideas. Beautifully presented.**

TeXora is a presenter built for **LaTeX Beamer** and PDF slides. You see your notes, the current
and next slide and the time; the room sees only the slide.

It compiles your Beamer source by itself, with pdfLaTeX, XeLaTeX or LuaLaTeX, and rebuilds the slides
every time you save the file in your editor.

TeXora is free for non-commercial use, and its source code is open to read on GitHub.

**Think clearly. Create beautifully. Present confidently.**
