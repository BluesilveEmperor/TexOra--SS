# 开始使用

要在终端中使用 TeXora，选择 **? > 命令行工具**。想看这台电脑上为 TeXora 准备了什么，选择 **? > 系统检查**。

在起始页打开 PDF 或 LaTeX 文件，也可以把文件拖到窗口里。选择 **新建 LaTeX 演示文稿**，可从九个模板中挑一个，每个都有自己的配色与风格：经典绿、午夜、极简白、会议和日出，以及四个带动画的模板——动态实验室、翻页书、媒体工作室和视频指南，它们的幻灯片里会播放动画、GIF 逐帧画面和视频片段。**视频指南**逐页讲解 `\includevideo`，并附带一个在幻灯片内播放的视频和一个 GIF。用你自己的 LaTeX 编辑器写演示文稿：每次保存，TeXora 都会重新编译幻灯片。最近打开的文件会留在起始页。

## 做演讲

- 按 **F5** 打开观众窗口。有第二块屏幕时，它会在那块屏幕上全屏显示；只有一块屏幕时，按 **F11**。
- 用方向键、空格键或 Page Up 和 Page Down 翻页。加上 **Shift** 可跳过一张幻灯片中的叠加步骤。
- 幻灯片编号周围的按钮可跳到第一张、上一张、下一张和最后一张。
- 要跳到某张幻灯片，点击工具栏上的编号，或按 **G**，输入编号后按 Enter。
- 按 **O** 打开概览，按 **Backspace** 回到原来的位置。
- 顶部一行显示你的准备情况：有几块屏幕、是否设定了时长、是否找到了备注，旁边是当前时间。**演示**按钮的作用和 **F5** 相同；观众窗口打开时，这一行显示的是观众看到的内容。
- 主面板下方依次是计时器、前后翻页箭头，中间是幻灯片编号和叠加步骤。
- 最下面一行按颜色显示你演讲的各个章节，黑色标记是你现在的位置。点击某个章节即可跳到它的第一张幻灯片。

## 视图

- **演讲者视图**：你的备注，配当前和下一张幻灯片。
- **大幻灯片**：幻灯片铺满主区域，备注在旁边，绘图工具在左侧。
- **分屏（S）**：幻灯片和备注并排放在一个窗口里。拖动分隔线可以调整两者的大小。
- **概览（O）**：所有幻灯片一览无余。

每个面板都会自行适应所在空间。在任何视图里，都可以拖动面板之间的分隔线来调整大小。双击分隔线可让它重新自动适应，也可以在「视图」菜单中选择 **自动适应所有面板**。

## 标签页

每份演示文稿在顶部都有自己的标签页，就像浏览器一样。切换标签页会保留你的位置、备注、批注和计时器，正在走的计时也会继续。打开文件后主页会关闭；左上角的 TeXora 图标可以把它叫回来。按标签上的 **x**，或按 **Cmd/Ctrl+W**，即可关闭标签页；你的工作会先被保存。关掉最后一份演示文稿会回到主页，而在没有其他内容打开的情况下关掉主页，就会退出 TeXora。你用别的标签页时，观众窗口始终留在它自己的那份演示文稿上。

## 书签与疑问

- 按书签按钮，或按 **M**，给当前幻灯片加书签；再按一次即可取消。
- 按疑问按钮，或按 **Q**，标记有人提问的那张幻灯片。

标记只有你自己看得见，观众永远看不到；书签还会显示在底部的章节线上。它们随演示文稿一起保存。打开 **目录（T）** 可以看到全部标记并跳转过去。每个章节有自己的书签颜色：点击章节旁边的小圆点就能改。

## 观众屏幕

- **B** 显示黑屏。
- **W** 显示白屏，你可以直接在上面写。
- **F** 把观众锁定在当前这张幻灯片上，你可以私下往后看。

## 计时器

计时器在主面板下方、幻灯片编号的左边。点击已用时间旁边的时长（未设置时显示 **设置时长**）可以设定演讲长度；底部随后会显示剩余时间，或你领先、超前了多少。落后时，右下角会出现一个按钮，让你跳过接下来几张幻灯片以把时间追回来。用播放、暂停和停止按钮即可，也可以直接点击已用时间来暂停和继续。停止会把计时归零，并把这次记录保存下来供「数据分析」使用。当前时间在顶部一行，**演示**旁边。

## 缩放

在幻灯片上滚动鼠标滚轮，或在触控板上双指捏合，就能以指针为中心缩放。这对当前幻灯片、下一张幻灯片和 PDF 备注页都有效，在任何视图里都一样。对当前幻灯片还可以用工具栏按钮或 **+**、**-**、**0** 这几个键。放大后可拖动来移动画面，双击则恢复适配。在文字备注上，同样的手势用来改变文字大小。

## 批注与指示

- **D** 画笔，**H** 荧光笔，**X** 橡皮擦。
- **L** 激光笔，颜色在工具栏里选。
- **Z** 然后拖动，放大某个区域。
- **V** 回到普通指针。

## 演讲者备注

备注可以来自 PDF 中的备注页、LaTeX 里的 `\note{}`，也可以来自与演示文稿同目录、以它命名的备注文件：`Lecture.pdf` 对应 `Lecture.note.md`（**设置 > 演讲者备注**里显示确切的文件名）。旧版本保存的 `Lecture.notes.md` 同样会被读取。在这个文件里，每个 `## Slide N` 标题就是一张幻灯片的备注开头。

要编辑当前幻灯片的备注，按指针旁边的备注按钮，或按 **E**。输入后按对勾或 **Cmd/Ctrl+Enter** 保存，按叉号或 **Esc** 取消。在没有备注的幻灯片上，**写备注** 起同样作用。对 PDF，备注保存在该文件旁边（`Lecture.pdf` 对应旁边的 `Lecture.note.md`）；对 `.tex` 演示文稿，备注直接保存在源码里，即幻灯片中的 `\note{...}`，这样演讲者视图和 LaTeX 工作室看到的备注始终一致。备注保存后立刻显示，幻灯片在后台重新编译。若想保持 .tex 文件不变，可以在编辑器下（或 **设置 > 演讲者备注** 中）取消勾选 **同时保存到 .tex 文件**：这样备注就写进 `.note.md` 文件，和 PDF 的情形一样。无论哪种方式，下次打开演示文稿时备注都在。保存时若没有文字，就删除这张幻灯片的备注。备注可以用任何语言书写；阿拉伯语按从右往左的方向输入和显示。备注以 UTF-8 保存。「视图」菜单决定显示哪些备注。文字备注支持 **粗体**、*强调*、列表和标题。要生成 PDF 备注页，在 Beamer 导言区加上：

```
\setbeameroption{show notes on second screen=right}
```

## LaTeX 工作室

打开一个 `.tex` 文件，然后按 **Cmd/Ctrl+E**、点工具栏上的工作室按钮，或选择 **视图 > LaTeX 工作室**。左边是源码，右边是幻灯片和它的备注，底部是编译信息。

- 输入不会自动触发编译：按 **编译**（Cmd/Ctrl+B），或打开 **保存时重新编译** 后按 **保存**（Cmd/Ctrl+S）。
- 键盘焦点始终留在编辑器里，即使你点了按钮或幻灯片也是如此。
- **编译**（Cmd/Ctrl+B）立刻构建；**保存**（Cmd/Ctrl+S）保存源码。
- 双击一张幻灯片可以定位到它的源码。移动光标会显示对应的幻灯片（**跟随光标**）。
- **Cmd/Ctrl+/** 注释当前行或选中的行；若这些行都已被注释，则取消注释。**Cmd/Ctrl+]** 注释，**Cmd/Ctrl+[** 取消注释。可在设置中更改。
- 行号旁的箭头可以折叠 `\begin{…}` … `\end{…}` 块、一个章节、导言区或一段很长的 `{…}` 组；再点一次（或点「⋯ N 行」标签）即可展开。绿色标记表示光标所在的块。
- 底部面板容纳问题、软件包和完整日志；错误排在前面，然后是警告（警告不会中断构建）。拖动它的上边缘可以调整高度。
- 拖动源码与预览之间的边缘，可以让任意一侧更宽。双击边缘可以恢复成各占一半。
- **检查所需的软件包**（在「工具」菜单里也有）会列出你的文件所缺的一切，以及如何获取。**设置 > 所需的 LaTeX 软件包**显示的是同一份清单。
- 你也可以继续用你自己的 LaTeX 编辑器：每次保存，幻灯片都会重新编译。

TeXora 需要安装 TeX Live、MacTeX 或 MiKTeX 才能编译。它会自行选择 pdfLaTeX、XeLaTeX 或 LuaLaTeX，你也可以手动指定。PDF 演示文稿则不需要任何额外东西。

## 动画与视频

用 LaTeX **animate** 宏包制作的动画会在幻灯片上播放，和在 Adobe Acrobat 里一样。设为 `autoplay` 的动画会在其幻灯片出现时开始播放，翻页时停止；`loop` 和 `palindrome` 也一样，按动画自身的速度播放。点击动画可播放或暂停。在演讲者视图里，动画下方那一条有第一帧、上一帧、播放/暂停、下一帧和最后一帧按钮，观众看到的也是同一帧。

视频和 GIF 也可以在幻灯片**内部**播放。GIF 会自行播放；**MP4 播放需要你电脑上安装 VLC 或 ffmpeg**（ffmpeg 在幻灯片内播放，VLC 在自己的窗口里播放；可在 **设置 > 视频** 中选择，那里还有一个「测试」按钮）。TeXora 本身不含视频解码器，也从不替你安装；当视频需要一个播放器而系统里找不到时，它会说明情况，并给出获取 VLC、获取 ffmpeg 和复制安装命令这几个选项。视频的声音由 ffmpeg 附带的 ffplay 一同播放；只用 VLC 时，VLC 会在自己的窗口里播放声音（**设置 > 视频 > 播放声音**；`mute` 选项让某一段片子静音，在 VLC 里也一样）。写上 `\usepackage{texoravideo}` 和 `\includevideo[width=0.5\textwidth]{clip.mp4}`（TeXora 会自己找到这个宏包）。第二个可选参数接受 `autoplay`、`loop`、`posterat=25` 或 `poster=cover.png`。视频必须放在 `.tex` 文件所在文件夹中，或其内部的文件夹里；若在子文件夹中，要把文件夹名也写上，如 `{videos/clip.mp4}`。编译时，TeXora 会在 `texora-video` 文件夹里为每个视频生成一张封面图，这样任何 PDF 阅读器都能显示封面；在 TeXora 里，点击可播放或暂停该片段，切到另一张幻灯片会停掉它。不是视频的文件、演示文稿文件夹之外的文件，以及找不到的视频，都会在封面上显示提示。

用 `\movie`（multimedia）或 `\includemedia`（media9）加入的视频片段，会在你的屏幕上显示一个播放按钮。点击片段即可用电脑上的视频播放器播放；设为自动开始的片段会在其幻灯片出现、且观众窗口打开时自动播放。`\movie` 引用的文件要和演示文稿放在同一文件夹里。

## 演讲之后

**数据分析（Y）**显示每张幻灯片花掉的时间、哪些地方值得注意，以及这次演讲和上一次相比如何。你标记过的疑问也会在这里统计。

## 更新

TeXora 启动时会查找新版本，之后每隔几小时也会再查一次。有新版本时，右下角会自动弹出一条提示：**看看有什么新内容**显示改动内容和适合这台电脑的下载链接，**稍后**把它藏到下次启动 TeXora 再说，**跳过此版本**则一直藏到有更新的版本出现。无论哪种做法，**?** 按钮上都会留一个小圆点。观众窗口打开时不会出现这条提示。想随时手动检查，可在 **?** 菜单中选择 **检查更新**。也可以在 **设置** 里关掉自动检查。

## 键盘快捷键

所有快捷键都列在 **设置** 里。点击其中一项，再按下新键即可更改。
